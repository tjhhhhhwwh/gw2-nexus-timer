世界计时首版，面向 Nexus，Windows x64。

- 查看24项世界BOSS/大型事件的下次计划刷新时间、倒计时和每日完整时刻。
- 一键复制名称、时刻、地图和传送点代码。
- CN / EN 界面切换，名称、地图、日期提示、复制文本同步切换并保存语言选择。
- Ctrl+Shift+T 显示或隐藏面板，支持名称/地图筛选。
- 更新源配置为 https://github.com/tjhhhhhwwh/gw2-nexus-timer 的 Releases。

所有时刻固定为北京时间（UTC+8）；语言切换不改变服务器或时区。时刻表不能表示地图实例的真实战斗进度。

安装：先安装 Nexus，退出游戏，把 `gw2_nexus_timer.dll` 放入游戏目录的 `addons/`，再启动游戏并在 Nexus 中启用插件。

验证：核心跨午夜、UTC+8、刷新边界、排序和中英文复制文本测试通过；已在 macOS 上交叉编译 Windows x64 DLL 并检查插件入口导出。Visual Studio 原生构建和真实客户端兼容性仍待验证。
