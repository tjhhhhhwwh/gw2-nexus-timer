世界计时 v0.1.1 预发布版，适用于 Windows x64 和 Nexus。

- 面板默认宽度从 780 调整为 600，保持字号和 48 像素缩略图。
- 复制传送点按钮保留 132 × 30 的点击区域，同时复制首领名称、刷新时刻、地图和传送点代码。
- 支持 CN / EN，内置 24 张首领图片，查看北京时间的刷新时刻和倒计时。

安装时先退出游戏，将附件 `gw2_nexus_timer.dll` 放进游戏目录的 `addons`，已安装旧版时直接替换同名文件。重新启动游戏后在 Nexus 中启用插件，按 `Ctrl+Shift+T` 可开关面板。

旧版已验证可以在游戏中加载。本版已通过构建和数据测试，紧凑布局请以游戏内显示为准。Nexus 检查 GitHub 预发布版本需要在设置中允许预发布更新。
