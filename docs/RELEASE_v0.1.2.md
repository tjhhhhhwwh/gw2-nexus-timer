# 世界计时 v0.1.2

- 界面调整为双列大图卡片；较窄窗口自动使用单列，放大首领名与计时。
- 红色「计划进行中」显示计划开始后15分钟内的已过时间，黄色「即将开始」为15分钟内开始，灰色「尚未开始」为更晚时刻。
- 计划开始后15分钟内的项目保留在列表前方，不再刚到刷新时间就直接跳到下一轮；已开始的卡片显示「本次」时刻。
- 点击图片/名称查看全天时刻，点击地图与传送点复制名称与传送点；保留 CN/EN 切换与筛选。
- 修正跨午夜已开始项目的「昨天」复制文本；补充刷新边界、15分钟展示边界和排序测试。
- 修复 Windows 默认 GBK 环境的图片数据测试；支持 Visual Studio 2022 / 2026 原生构建，静态链接运行库。

沿用原有24项首领/大型事件、246个每日计划时刻，本版没有改动时刻表。
「计划进行中」是固定时刻表的展示窗口，不能据此确定地图实例中的事件已经触发或仍在进行。
已在 Windows x64 原生构建和测试，并检查独立 ImGui 渲染预览；仍需在国服 Nexus 真实客户端验证。
