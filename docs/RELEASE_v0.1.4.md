# 世界计时 v0.1.4

- 将难以辨认的斜角状态小字改为16像素横向标签，位于计时数字上方；红色「计划进行中」、黄色「即将开始」、灰色「尚未开始」，提高对比度。
- 上次/本次/下次时间、地图与传送点文字改为14像素，不再随卡片宽度自动缩成小字；悬停可查看完整信息。
- 使用独立16像素字体显示状态与说明，调整计时数字位置，为状态标签留出空间。窗口和卡片尺寸保持 v0.1.3 的紧凑布局。
- 保留双标签、11组分类、CN/EN、复制与固定北京时间时刻表。状态仍只代表计划，不能判断地图实例真实事件状态。

Windows x64原生构建，5项CTest通过；检查中英文、双列/窄窗口、卡片弹窗与筛选的独立ImGui预览。Nexus真实客户端的字体加载、剪贴板与卸载仍需验证。
